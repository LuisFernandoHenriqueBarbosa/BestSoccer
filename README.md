# BestSoccer
Projeto interdisciplinar desenvolvido durante a faculdade, integrando os conhecimentos das disciplinas de Linguagem de Programação II, Administração de Banco de Dados, Estatística, Gestão de Processos e Engenharia de Software. O trabalho teve como objetivo aplicar, de forma prática, os conceitos aprendidos nessas áreas para o desenvolvimento de uma solução completa e funcional.

# Sobre o Sistema
O BestSoccer é um sistema web criado para gerenciar informações de times de futebol amador da região de São José do Rio Preto. A plataforma permite o cadastro de jogos, registro de jogadores e acompanhamento de estatísticas individuais e coletivas, oferecendo uma forma organizada e acessível de centralizar os dados dos campeonatos de várzea.
