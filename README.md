# BestSoccer
Projeto interdisciplinar desenvolvido durante a faculdade, integrando os conhecimentos das disciplinas de Linguagem de Programação II, Administração de Banco de Dados, Estatística, Gestão de Processos e Engenharia de Software. O trabalho envolveu a aplicação prática dos conteúdos dessas áreas para a criação de uma solução completa e funcional.
